# ebook-langlearner

Annotate rare words in an EPUB with inline translations so language learners
can read literature just above their comfort level without constantly
reaching for a dictionary.

Given an EPUB and a target reader profile — a CEFR level (A1-C2) or a raw
Zipf-frequency cutoff — the tool walks every XHTML text node, detects words
that a reader at that level is unlikely to know, and wraps them in HTML
ruby annotations (`base<rt>translation</rt>`). The output is a standards-
compliant EPUB 3 that renders in Calibre, Apple Books, Kobo, recent Kindles,
and epub.js.

## Example

Input:

> La locomotive, aux ardents reflets du couchant, fendait la **brume**.

Output (rendered):

> La locomotive, aux ardents reflets du couchant, fendait la [brume]{Nebel}.

The underlying HTML:

```html
La locomotive, aux ardents reflets du couchant, fendait la
<ruby class="ell-annot">brume<rt class="ell-rt">Nebel</rt></ruby>.
```

## Install

Requires Python 3.10+ and [uv](https://github.com/astral-sh/uv) (or `pip` in
a virtualenv).

```bash
uv sync
```

This installs the `ebook-langlearner` command into `.venv/bin`. Run it via
`uv run ebook-langlearner ...`.

## Quick start

```bash
uv run ebook-langlearner annotate book.epub \
    --from fr --to de \
    --level b2 \
    --dictcc /path/to/fr-de-dict.cc.txt \
    --output book.b2.epub
```

`--level b2` is a shorthand; use `--cutoff 3.5` to pass a Zipf cutoff directly.

## CEFR levels and cutoffs

`--level a1|a2|b1|b2|c1|c2` picks a per-language Zipf cutoff calibrated so
that a reader at that level is assumed to know the top-N lemmas of their
target language, where N is the CEFR receptive-vocabulary target (A1≈750,
B1≈2500, C1≈8000, C2≈16000). The calibration table lives at
`src/ebook_langlearner/data/cefr_cutoffs.json` and can be regenerated by
`scripts/build_cefr_cutoffs.py`.

Levels are per-language: French B1 sits at Zipf 4.51, German B1 at 4.50,
Polish B1 at 4.63 — the raw cutoff differs because morphologically rich
languages spread surface frequency across many inflected forms. Using a
single hand-picked cutoff would systematically under- or over-annotate
depending on the language.

Words are annotated only when *both* the surface Zipf and the
lemma-aggregated Zipf fall below the cutoff. The second gate catches very
common verbs whose infinitive looks rare in isolation (e.g. French
*manger* surface Zipf ≈ 5.0 but lemma-aggregated Zipf ≈ 5.3 over all its
conjugations). The first gate catches very common inflected forms that a
lemmatizer might resolve to a rare noun homograph (the classic *étais*
→ *étai* "strut" bug).

## Dictionary backends

The annotator tries backends in this order:

1. **dict.cc exports**, one per `--dictcc` flag. Pass a tab-separated file
   from https://www.dict.cc/?s=about%3Aexport. Multiple can be chained; the
   first one with a hit wins.
2. **Wiktionary index**, built from a [Kaikki](https://kaikki.org) JSONL
   dump:

   ```bash
   uv run ebook-langlearner build-wiktionary-index \
       --source fr path/to/kaikki-fr.jsonl
   ```

   The resulting SQLite index is cached under the user's data directory
   (`platformdirs`) and picked up automatically on subsequent runs.

If no backend has a hit for a given lemma the word is left untouched.

## Annotation formats

- `--format ruby` (default) — wraps words in `<ruby>base<rt>translation</rt></ruby>`.
  Renders above the line in supporting readers (Calibre, Apple Books,
  modern Kindle, epub.js). A bundled stylesheet keeps line-heights uniform
  so ruby doesn't spread neighbouring lines apart.
- `--format parenthetical` — renders `word (translation)` inline. Fallback
  for readers without ruby support.

## Supported languages

```
$ uv run ebook-langlearner languages
de  German
en  English
es  Spanish
fr  French
it  Italian
nl  Dutch
pl  Polish
pt  Portuguese
sv  Swedish
```

All combinations of source and target are valid provided a dictionary
backend exists for that pair.

## How it works

```
EPUB → ebooklib → per-document BeautifulSoup (lxml-xml)
   → walk every text node
      → tokenize (Unicode letter runs + punctuation)
         → for each word token:
              length / numeric / proper-noun gates (cheap short-circuit)
              surface-form Zipf gate (wordfreq)
              lemma-aggregated Zipf gate (precomputed table)
              dictionary lookup (dict.cc → Wiktionary fallback)
              rank candidates (target-language purity, translation length)
              render <ruby> / parenthetical
   → reinsert annotated HTML → write EPUB 3 with stylesheet
```

Precomputed data shipped in-package:

- `data/lemma_freq_{lang}.json.gz` — lemma-aggregated Zipf values, built from
  the full `wordfreq` wordlist folded onto `simplemma` lemmas
  (`scripts/build_lemma_frequencies.py`, ~600 KB-1.6 MB per language).
- `data/cefr_cutoffs.json` — per-language CEFR → Zipf cutoffs derived from
  the lemma-frequency table (`scripts/build_cefr_cutoffs.py`, a few hundred
  bytes).

```bash
uv sync --group dev          # installs dev tools (pytest, ruff, playwright)
uv run pytest                # unit + integration tests
```
